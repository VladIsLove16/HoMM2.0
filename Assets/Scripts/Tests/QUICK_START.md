# Быстрый старт тестирования

## 🚀 Запуск тестов за 3 шага

### Шаг 1: Откройте Unity Test Runner
- В Unity: `Window > General > Test Runner`
- Или нажмите `Ctrl+Shift+T` (Windows) / `Cmd+Shift+T` (Mac)

### Шаг 2: Выберите тип тестов
- **EditMode** - быстрые тесты в редакторе
- **PlayMode** - тесты в runtime (требуют больше времени)

### Шаг 3: Запустите тесты
- Нажмите `Run All` для всех тестов
- Или выберите конкретные тесты и нажмите `Run Selected`

## 📊 Что тестируется

| Класс | Тесты | Описание |
|-------|-------|----------|
| **UnitModel** | 25+ | Модель юнита, бой, движение, эффекты |
| **UnitViewModel** | 15+ | ViewModel, материалы, события |
| **UnitView3D** | 20+ | 3D представление, анимации, UI |
| **Интеграция** | 10+ | Взаимодействие компонентов |

## ⚡ Быстрые команды

### Запуск всех EditMode тестов
```
EditMode > Run All
```

### Запуск всех PlayMode тестов
```
PlayMode > Run All
```

### Запуск конкретной группы тестов
```
EditMode > GridContents > Units > Run Selected
```

## 🔍 Просмотр результатов

- **Зеленый** ✅ - тест прошел
- **Красный** ❌ - тест упал
- **Желтый** ⚠️ - тест пропущен

## 🛠️ Отладка

### Тест не компилируется?
- Проверьте `TROUBLESHOOTING.md`
- Убедитесь, что все зависимости подключены

### Тест падает?
- Нажмите на тест в Test Runner
- Посмотрите детали ошибки
- Используйте точки останова для отладки

## 🎯 Лучшие практики

1. **Запускайте тесты часто** - после каждого изменения
2. **Исправляйте падающие тесты** - не игнорируйте ошибки
3. **Добавляйте новые тесты** - для нового функционала
4. **Используйте Mock объекты** - для изоляции тестов

## 📈 Метрики качества

- **Покрытие тестами**: стремитесь к 80%+
- **Время выполнения**: EditMode < 10 сек, PlayMode < 60 сек
- **Стабильность**: тесты должны проходить стабильно
